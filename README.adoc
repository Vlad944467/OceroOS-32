**32-битная монолитная ОС с TUI (Text User Interface), написанная на C и Assembly**

Работает на реальном железе (BIOS) и в эмуляторах (QEMU).

image:https://via.placeholder.com/800x450/0x0000AA/0xFFFFFF?text=OceroOS-32+TUI[OceroOS-32,800,450]

== Возможности

=== Ядро и система
* 32-битный защищённый режим
* Загрузка по стандарту Multiboot (GRUB)
* Монолитное ядро
* Собственный шелл с историей команд

=== Драйверы
* Клавиатура PS/2
* VGA текстовый режим (80x25, 16 цветов)
* ATA/PATA драйвер (чтение/запись секторов)
* PC Speaker (звук)

=== Файловая система
* OFS — собственная файловая система
* Создание, чтение, запись файлов

=== Интерфейс
* Псевдографические окна (TUI)
* Рамка по краям экрана (как в BIOS/TempleOS)
* Текстовый редактор
* Команды для работы с файлами

=== Загрузка программ
* ELF-загрузчик (запуск 32-bit программ)
* Поддержка статически скомпилированных ELF

== Сборка и запуск

=== Требования

Для Ubuntu/Debian:

[source,bash]
----
sudo apt install gcc nasm qemu-system-x86 make
sudo apt install gcc-multilib
----

=== Ручная сборка

[source,bash]
----
# Сборка загрузчика
nasm -f elf32 src/boot/boot.asm -o boot.o

# Компиляция ядра
gcc -m32 -ffreestanding -nostdlib -c src/kernel/PMocero.c -o PMocero.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/commands.c -o commands.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/read_keyboard.c -o read_keyboard.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/ata.c -o ata.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/video.c -o video.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/elf.c -o elf.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/init.c -o init.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/Twindows.c -o Twindows.o
gcc -m32 -ffreestanding -nostdlib -c src/kernel/fs/OFS.c -o OFS.o

# Линковка
ld -m elf_i386 -T src/boot/linker.ld -o OceroOS.elf boot.o PMocero.o commands.o read_keyboard.o ata.o video.o elf.o init.o Twindows.o OFS.o
----

=== Сборка через Makefile

[source,bash]
----
make          # Собрать ядро
make clean    # Очистить объектные файлы
make rebuild  # Пересобрать с нуля
make run      # Запустить в QEMU
----

=== Запуск в QEMU

[source,bash]
----
# Только ядро
qemu-system-i386 -kernel OceroOS.elf

# С диском (для ATA/OFS)
qemu-system-i386 -kernel OceroOS.elf -hda fat16.img

# С отладкой
qemu-system-i386 -kernel OceroOS.elf -serial stdio
----

=== Запуск на реальном железе

[source,bash]
----
# 1. Собрать ISO-образ
grub-mkrescue -o OceroOS-32.iso iso/

# 2. Записать на флешку
sudo dd if=OceroOS-32.iso of=/dev/sdX bs=4M status=progress

# 3. Загрузиться с флешки (BIOS/Legacy режим)
----

== Команды

=== Основные команды

[cols="1,3"]
|===
| Команда | Описание
| `help` | Показать справку
| `clear` | Очистить экран (с сохранением рамки)
| `reboot` | Перезагрузить систему
| `shutdown` | Выключить систему
| `echo <текст>` | Вывести текст
| `edit` | Текстовый редактор
| `notes` | Показать сохранённую заметку
| `save` | Сохранить заметку на диск
| `load` | Загрузить заметку с диска
| `bgcolor <0-F>` | Сменить цвет фона
| `fetch` | Показать информацию об ОС
| `ls` | Список файлов в OFS
| `cat <файл>` | Показать содержимое файла
| `write <файл> <текст>` | Создать/перезаписать файл
| `run <сектор>` | Запустить ELF-программу с диска
| `settings` | Меню настроек (Reboot/Shutdown/Cancel)
|===

=== Оконные команды (TUI)

[cols="1,3"]
|===
| Команда | Описание
| `note2` | Показать заметку в окне
| `disk` | Информация о диске в окне
| `tt` | Тестовое окно
|===

=== Табличные команды (через `par`)

[cols="1,3"]
|===
| Команда | Описание
| `par help` | Справка по табличным командам
| `par hello` | Приветствие
| `par time` | Показать время
| `par calc 2+3` | Калькулятор
| `par sleep 5` | Пауза на N секунд
| `par bgcolor 1` | Сменить цвет фона
| `par edit` | Редактор
| `par clear` | Очистка экрана
|===

=== Команда `run`

Загружает и запускает ELF-программу с диска.

[source,bash]
----
run 10
----

Программа должна быть скомпилирована статически для 32-bit x86 и записана в указанный сектор.

==== Компиляция программы

[source,bash]
----
# Сборка программы
gcc -static -m32 -nostdlib -fno-stack-protector -no-pie -Wl,-Ttext=0x100000 -o hello.elf hello.c

# Запись в сектор 10
sudo dd if=hello.elf of=fat16.img bs=512 seek=10 conv=notrunc
----

==== Пример программы `hello.c`

[source,c]
----
void _start() {
    char *video = (char*)0xB8000;
    char *msg = "Hello from OceroOS-32!";
    for (int i = 0; msg[i]; i++) {
        video[i * 2] = msg[i];
        video[i * 2 + 1] = 0x0F;
    }
    while (1);
}
----

== Архитектура TUI

Оконная система OceroOS-32 построена на псевдографике (текстовый режим VGA 80x25):

* **Рамка экрана**: двойная рамка `╔═╗ ║ ╚═╝` по краям (как в BIOS/TempleOS)
* **Окна**: сохраняют фон при открытии и восстанавливают при закрытии
* **Цвета**: настраиваются через команду `bgcolor`

== Планы

=== Ближайшие (до 1.0)

* [ ] Поддержка мыши (PS/2)
* [ ] Движение окон (Alt + стрелки)
* [ ] Несколько окон (переключение Tab)
* [ ] Двойная буферизация для окон

=== Среднесрочные

* [ ] Многозадачность (переключение процессов)
* [ ] Поддержка FAT32 (чтение файлов)
* [ ] Собственный загрузчик (без GRUB)
* [ ] Графический режим VBE

=== Долгосрочные

* [ ] Сетевая подсистема (TCP/IP)
* [ ] Поддержка USB
* [ ] Звуковой драйвер (SoundBlaster)
* [ ] Поддержка UEFI

== Известные проблемы

* Не работает на UEFI-системах (только BIOS/Legacy)
* Нет поддержки мыши
* Только текстовый режим (без графики)
* Нет многозадачности

== Зависимости

=== Системные

* `gcc` (с поддержкой `-m32`)
* `nasm`
* `ld`
* `qemu-system-x86` (для запуска)
* `make`
