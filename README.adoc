**32-битная монолитная ОС, написанное на C и Assembly**


== Возможности

* 32-битный защищённый режим
* Загрузка по стандарту Multiboot (GRUB/QEMU)
* Поддержка клавиатуры PS/2
* Текстовый режим VGA (80x25, 16 цветов)
* Звук через PC Speaker
* Запуск ELF программ
* Встроенные команды: `help`, `clear`, `reboot`, `echo`, `win`, `cat`, `fetch`, `run`, `settings`
* ATA драйвер (чтение/запись секторов)
* OFS — собственная файловая система
* Текстовые окна (псевдографика)
* Собственный шелл с историей команд
* Монолитное ядро


== Сборка и запуск

=== Ручная сборка

.Сборка загрузчика
[source,bash]
----
nasm -f elf32 boot/boot.asm -o boot.o
----

.Компиляция ядра
[source,bash]
----
gcc -m32 -ffreestanding -nostdlib -c kernel/PMocero.c -o PMocero.o
gcc -m32 -ffreestanding -nostdlib -c kernel/commands.c -o commands.o
gcc -m32 -ffreestanding -nostdlib -c kernel/read_keyboard.c -o read_keyboard.o
gcc -m32 -ffreestanding -nostdlib -c kernel/ata.c -o ata.o
gcc -m32 -ffreestanding -nostdlib -c kernel/video.c -o video.o
gcc -m32 -ffreestanding -nostdlib -c kernel/elf.c -o elf.o
gcc -m32 -ffreestanding -nostdlib -c kernel/init.c -o init.o
gcc -m32 -ffreestanding -nostdlib -c kernel/fs/OFS.c -o OFS.o
gcc -m32 -ffreestanding -nostdlib -c kernel/windows.c -o windows.o
----

.Линковка
[source,bash]
----
ld -m elf_i386 -T boot/linker.ld -o OceroOS.elf boot.o PMocero.o commands.o read_keyboard.o ata.o video.o elf.o init.o OFS.o windows.o
----

=== Сборка через Makefile

[source,bash]
----
make
make clean
make rebuild
make run
----

=== Запуск в QEMU

[source,bash]
----
qemu-system-i386 -kernel OceroOS.elf
----

=== Запуск с диском (для ATA/OFS)

[source,bash]
----
qemu-system-i386 -kernel OceroOS.elf -hda fat16.img
----

|===

=== Команда `run`

Загружает и запускает ELF-программу с диска.

[source,bash]
----
run 10
----

Программа должна быть скомпилирована статически для 32-bit x86 и записана в указанный сектор.

==== Компиляция программы

[source,bash]
----
gcc -static -m32 -nostdlib -fno-stack-protector -no-pie -Wl,-Ttext=0x100000 -o hello.elf hello.c
sudo dd if=hello.elf of=fat16.img bs=512 seek=10 conv=notrunc
----

==== Пример программы `hello.c`

[source,c]
----
void _start() {
    char *video = (char*)0xB8000;
    char *msg = "Hello from OceroOS-32!";
    for (int i = 0; msg[i]; i++) {
        video[i * 2] = msg[i];
        video[i * 2 + 1] = 0x0F;
    }
    while (1);
}
----


== Зависимости

* `gcc` (с поддержкой `-m32`)
* `nasm`
* `ld`
* `qemu-system-x86` (для запуска)
* `make`

Для Ubuntu/Debian:

[source,bash]
----
sudo apt install gcc nasm qemu-system-x86 make
sudo apt install gcc-multilib
----
