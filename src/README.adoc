= OceroOS-32 — Ядро

== Описание

Это ядро 32-битной операционной системы, написанное с нуля на C и ассемблере.  
Оно загружается через GRUB, работает в защищённом режиме и имеет свой TUI-интерфейс.

=== Основные файлы

* `PMocero.c` — главный файл ядра, точка входа
* `commands.c` — все команды TUI
* `video.c` — работа с VGA видеопамятью
* `ata.c` — драйвер ATA для работы с диском
* `read_keyboard.c` — драйвер PS/2 клавиатуры
* `elf.c` — загрузчик ELF-файлов
* `init.c` — инициализация системы
* `Twindow.c` — псевдографические окна

=== Файловая система

* `fs/` — папка с файловой системой OFS
* `fs/OFS.c` — реализация файловой системы

== Зависимости

Для сборки нужны:

* nasm — ассемблер
* gcc — компилятор
* ld — линковщик
* grub-mkrescue — для создания ISO
